# **App Name**: EffortEase Tasks

## Core Features:

- Task Input & Creation: Users can input and submit new task descriptions via a dedicated text field.
- AI Task Difficulty Ranking Tool: Automatically rank newly created tasks as 'Easy', 'Medium', or 'Hard' based on AI analysis of the task description.
- Task Persistence: Tasks, along with their assigned difficulty, are saved to a database and retrieved upon app load.
- Interactive Task List Display: Display a list of all tasks, clearly indicating their difficulty with color coding and completion status.
- Task Completion Toggle: Users can mark tasks as completed or incomplete, updating their status visually in the list.

## Style Guidelines:

- Primary/Accent Color: A vibrant light blue (#00BFFF, Sky Blue) for interactive elements, highlights, and calls to action, maintaining a modern and engaging feel.
- Dark Mode Background: A deep charcoal gray (#121212) or rich black for the main application background, providing a sleek, modern dark theme.
- Text Colors: Various shades of white and light gray (#E0E0E0, #B0B0B0) for text and secondary UI elements, ensuring high readability against the dark background.
- Neutral UI Elements: Black and gray tones will be used for borders, separators, and non-interactive components to maintain a clean, minimalist aesthetic within the dark mode.
- Difficulty Indicator Colors: 'Easy' tasks in green (#28A745), 'Medium' in orange (#FFC107), and 'Hard' in red (#DC3545) for immediate visual identification, specifically chosen to stand out clearly in a dark theme.
- All text will use 'Inter', a grotesque-style sans-serif font. It is chosen for its excellent readability and neutral, objective appearance, suitable for both headlines and body text, ensuring a clean and modern feel.
- Utilize simple, clean line icons (e.g., checkmarks, edit pens, trash cans) to maintain a modern and minimalist aesthetic. Icons should subtly complement the primary light blue or be rendered in white/light gray for visibility.
- A clean, single-column layout, centrally aligned for focus, optimized for a modern dark mode interface. The top section will feature the task input field, followed by a scrollable list of tasks, each presented within distinct, easily digestible cards or rows, designed for clarity and easy navigation.
- Subtle, fluid animations will be incorporated for actions like adding new tasks, marking tasks as complete, or deleting tasks. These provide smooth visual feedback without being distracting, enhancing the overall user experience.
